# نمایندگی‌های ما — قالب تک‌صفحه‌ای

قالب تک‌صفحه‌ای، راست‌چین و واکنش‌گرا برای معرفی شبکه نمایندگی‌های یک برند در
استان‌های ایران، با نقشه تعاملی و فرم چندمرحله‌ای درخواست نمایندگی. بدون نیاز
به فریم‌ورک یا مرحله بیلد — فقط HTML/CSS/JS خالص.

## ساختار پروژه

```
index.html                        صفحه اصلی (تک‌صفحه با اسکرول به بخش‌ها)
representatives.html              فهرست نمایندگان یک استان — از نقشه یا representatives.html?province=<slug> باز می‌شود
assets/css/style.css              تمام استایل‌ها و توکن‌های طراحی
assets/js/main.js                 منطق ناوبری، نقشه، انیمیشن، فرم، آکاردئون (فقط index.html)
assets/js/representatives.js      منطق صفحه فهرست نمایندگان: جست‌وجو، فیلتر شهر/رسته، رندر کارت‌ها
assets/js/provinces-data.js       نام فارسی، مرکز استان و تعداد نمایندگان هر استان (داده نمونه)
assets/js/representatives-data.js تولید نمونه‌داده نمایندگان هر استان (بدون بک‌اند — پایین را ببینید)
assets/svg/iran-map.svg           نقشه ۳۱ استان ایران (ISC License)
scripts/generate-map-labels.mjs   بازتولید مختصات برچسب نام استان‌ها روی نقشه (فقط اگر iran-map.svg تغییر کند)
```

## اجرای محلی

نقشه با `fetch()` بارگذاری می‌شود، بنابراین باید از طریق یک وب‌سرور محلی اجرا
شود (نه به‌صورت مستقیم با `file://`):

```bash
python3 -m http.server 8080
# سپس مرورگر را باز کنید: http://localhost:8080
```

## استقرار روی ساب‌دامین

این پروژه یک سایت استاتیک است؛ کافی است محتوای این پوشه را روی هاست/ساب‌دامین
موردنظر (مثلاً `namayandegi.example.com`) آپلود کنید — هیچ بیلد یا Node.js در
زمان اجرا لازم نیست.

## چیزهایی که باید پیش از انتشار جایگزین کنید

| مورد | محل |
|---|---|
| نام برند و لوگو | `.brand` در `index.html` و `representatives.html` |
| اطلاعات تماس فوتر و بنر CTA | بخش `footer-contact` و لینک `tel:` |
| تعداد نمایندگان هر استان | `assets/js/provinces-data.js` (کامنت بالای فایل را ببینید) |
| نظرات نمایندگان | بخش `#testimonials` در `index.html` — نمونه/جای‌گیر است |
| اتصال فرم به بک‌اند واقعی | `TODO(backend)` در `assets/js/main.js` داخل `initForm()` |
| فهرست واقعی نمایندگان هر استان | `window.generateRepresentatives` در `assets/js/representatives-data.js` — همین حالا نمونه‌داده تصادفی (اما تکرارپذیر) می‌سازد؛ آن را با یک `fetch()` به API واقعی جایگزین کنید. بقیه صفحه (کارت‌ها، جست‌وجو، فیلترها) به همان شکل با آرایه واقعی کار می‌کند |
| آدرس و شماره تماس نمایندگان | داخل همان generator — الگوی ماسک‌شده (`۰۹۱۲-۰۰۰-xxxx`) مثل شماره فوتر است، نه شماره واقعی |

## نکات فنی

- **فونت:** Vazirmatn از Google Fonts، با `font-display: swap`.
- **انیمیشن:** GSAP (فقط core، بدون پلاگین) برای ورود هیرو و افکت رسم‌شدن
  مرز استان‌ها روی نقشه؛ برای بقیه بخش‌ها از `IntersectionObserver` استفاده
  شده. همه انیمیشن‌ها با `prefers-reduced-motion` غیرفعال/ساده می‌شوند.
- **دسترس‌پذیری:** فوکوس قابل مشاهده، برچسب‌های ARIA روی نقشه و فرم، ناوبری
  کامل با کیبورد (Tab/Enter/Space/Escape روی نقشه)، خطاهای فرم متصل به فیلد.
- **نقشه:** داده مسیر SVG از پکیج متن‌باز `iran-svg-map` (لایسنس ISC) گرفته
  شده؛ اعتبار در کامنت بالای `assets/svg/iran-map.svg` ذکر شده است. جانمایی و
  اندازه ۳۱ استان با موقعیت جغرافیایی واقعی آن‌ها تطبیق داده و تأیید شده
  (نسبت به هم، شرق/غرب و شمال/جنوب صحیح است). نام هر استان مستقیماً روی نقشه
  نوشته شده — نقطه لنگر هر برچسب (`cx/cy/r` در `provinces-data.js`) با یک
  الگوریتم «دورترین نقطه از مرز» محاسبه شده، نه مرکز باکس/سطح، چون برای
  استان‌های باریک یا مقعر (تهران، سمنان، گیلان، مازندران…) مرکز ساده بیرون از
  شکل یا روی استان همسایه می‌افتد.
- **صفحه نمایندگان:** جست‌وجو (نام/شهر) و فیلتر شهر/رسته شغلی کاملاً سمت
  کلاینت است و روی همان آرایه‌ای که `generateRepresentatives` برمی‌گرداند کار
  می‌کند. سه حالت جدا مدیریت می‌شود: استان بدون نماینده (دعوت به ثبت‌نام)،
  فیلتر بدون نتیجه (دکمه پاک‌کردن فیلترها)، و بدون پارامتر `province` معتبر
  در آدرس.
